Full System Design Overview

Knowledge Graph là canvas engine dùng chung. Fullstack Engineering chỉ là built-in Knowledge Pack; research hoặc curriculum khác có thể import thành workspace riêng, lưu local và dùng cùng projection/runtime.

Architecture flow

Read path, import/export path, local authoring và deployment được tách thành các boundary rõ ràng để sau này thay IndexedDB bằng authenticated API mà không phải viết lại canvas engine.

Workspace → runtime → delivery

Một engine, nhiều Knowledge Packs, cùng validation và projection contract.

Current architecture

System responsibilities

Knowledge Pack

Portable contract gồm manifest, canonical graph, overlay, optional profiles, view hints và inbox. Pack có thể import/export độc lập.

Workspace Repository

Built-in pack đọc từ static JSON; personal packs persist trong IndexedDB. Active workspace được resolve qua một data bridge trước renderer.

Canvas Engine

Không biết pack thuộc Fullstack, AI hay domain nào. Nó chỉ đọc graph contract và render các projection chung.

Import safety

  • Validate before IndexedDB write.
  • Reject duplicate / dangling IDs.
  • Reject invalid hierarchy cycles.
  • Keep learner state outside canonical nodes.
  • Check overlay and profile references.
  • Preview stats, warnings and errors before confirm.

Storage boundary

  • IndexedDB: imported/local Knowledge Packs.
  • localStorage: active workspace ID and lightweight preferences.
  • Knowledge Inbox is scoped per workspace.
  • Built-in Fullstack data stays cacheable static JSON.
  • No GitHub token exists in the public runtime.
