Core invariants

  • Stable node IDs.
  • Depth derived from contains.
  • No cycles in hierarchy.
  • All edge endpoints must exist.
  • Mastery belongs to overlay.
  • Career expectation belongs to profile.
  • No GitHub token in public site.
